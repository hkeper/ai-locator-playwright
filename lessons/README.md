# Конспекты уроков

Здесь хранится учебная часть каждого урока: теория, разбор кода, задания и вопросы с ответами.
Код урока хранится в git: после урока ставится тег `lesson-XX`.

## Уроки

| Урок | Тема | Тег |
|---|---|---|
| [Урок 0](lesson-00.md) | Подготовка: Node, git, GitHub, npm, package.json, lock-файл | `lesson-00` |
| [Урок 1](lesson-01.md) | Скелет проекта: package.json, зависимости, .gitignore, первый тест | `lesson-01` |
| [Урок 2](lesson-02.md) | tsconfig.json, playwright.config.ts, dotenv | `lesson-02` |
| [Урок 3](lesson-03.md) | TypeScript: типы, размеченные объединения, свой Error, requireEnv | `lesson-03` |

## Как устроена папка

- `lesson-XX.md` — конспект урока. Единственный формат хранения.
- Читать удобно в предпросмотре VS Code (Ctrl+Shift+V) или на GitHub.
- Позже из этих файлов соберём сайт-курс готовым генератором (VitePress или Astro Starlight). Сгенерированный HTML в git не хранится.

## Как вернуться к коду урока

```bash
git switch --detach lesson-01   # открыть проект в состоянии после урока 1
git switch main                 # вернуться к текущей работе
git diff lesson-01 lesson-02    # посмотреть, что изменилось за урок 2
```

## Порядок в конце каждого урока

1. Дописать `lessons/lesson-XX.md`, включая раздел «Ошибки и разбор», и добавить строку в таблицу выше.
2. Закоммитить конспект вместе с кодом урока и поставить тег `lesson-XX`.

## Примечание

Конспекты уроков 0–2 восстановлены после прохождения по заметкам в [LEARNING_PLAN.md](../LEARNING_PLAN.md) и коммитам.
Это выжимки, а не полный текст занятий. Начиная с урока 3, конспект пишется по ходу урока.
